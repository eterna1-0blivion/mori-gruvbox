## [1.0.0] — 2026-11-22

Первая версия.

### Добавлено

- **Тема VS Code `Mori Gruvbox Dark Hard`.** Gruvbox Dark Hard с нейтральным
  интерфейсом: подсветка синтаксиса остаётся Gruvbox, а панели, вкладки,
  бейджи, кнопки, прогресс, ссылки и элементы чата становятся серыми
  (`#181818` / `#1f1f1f` / `#2a2a2a`, границы `#2b2b2b`).
- **84 переопределения цветов UI** (`src/overrides.json`), включая 24 ключа
  `chat.*` — пузыри сообщений, аватар, блок запроса, рамка ввода при работе,
  разделители, шиммер «thinking».
- **Сборщик темы** `scripts/build-theme.mjs`: сливает upstream и наш слой,
  валидирует hex-цвета и детерминированно сортирует ключи. Режим `--check`
  для CI.
- **Патч интерфейса Mozg** (`mozg/mori-neutral.css`): убирает оранжевый акцент
  `#ff6a1a` из webview расширения `mori-ai.mori-code`, переводит палитру в
  серую и заменяет декоративные градиенты плоскими заливками.
- **Скрипты установки** с раздельными подтверждениями:
  - `install.ps1` — оркестратор, спрашивает про каждую часть отдельно;
  - `install-vscode-theme.ps1` — сборка `.vsix` и установка через CLI;
  - `install-mozg-theme.ps1` — патч CSS с режимами `-Status` и `-Revert`.
- **Защита от несовпадения структуры:** патч применяется только если в
  `index.css` есть `--mori-accent`; иначе файл остаётся нетронутым.
- **Идемпотентность:** повторный запуск заменяет блок по маркерам, а не
  дублирует его; байтовый размер и SHA256 стабильны.
- **Генератор иконки** `scripts/make-icon.ps1`.
- **GitHub Actions:** сборка `.vsix` на каждый push и прикрепление к релизу
  по тегу.

### Исправлено

- **Код 64 при запуске `install.ps1` из терминала VS Code.** Оркестратор
  оборачивал путь к подскрипту в кавычки внутри массива аргументов; PowerShell
  передавал их как литеральные символы, и `pwsh` завершался с кодом 64
  (`EX_USAGE`), а Windows PowerShell 5.1 — с ошибкой «Illegal characters in
  path». Кавычки убраны: экранирование выполняет сам PowerShell, пути с
  пробелами работают.

### Добавлено

- **Удаление устаревшего блока `"[Gruvbox Dark Hard]"`** из `settings.json`
  после успешной установки темы — отдельным вопросом, с бэкапом и проверкой,
  что файл остаётся валидным JSON.
- **Тесты** `scripts/tests/test-settings-block.ps1`: 16 проверок удаления
  блока на JSONC (комментарии, висячие запятые, `//` внутри URL, блок первым
  и последним в объекте). Проходят в PowerShell 5.1 и 7.

### Изменено

- Publisher и все ссылки: `eterna1-0blivion` вместо `vl4dislaw`.
  Идентификатор расширения — `eterna1-0blivion.mori-gruvbox`.

### Известные ограничения

- Патч Mozg переустанавливается вместе с расширением: после обновления Mozg
  скрипт нужно запустить снова (`-Status` покажет состояние).
- Скрипты рассчитаны на Windows (PowerShell). Сборка темы кроссплатформенная.
- Проверено на VS Code 1.147.0 и Mozg 0.2.15. Ключи `chat.*` в других версиях
  могут отличаться: неизвестные ключи VS Code игнорирует.

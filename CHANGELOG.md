# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [3.1.0] — 2026-11-23

Только документация и комментарии, поведение не менялось.

### Добавлено

- Указано авторство: весь код написан нейросетью Mozg AI под руководством и
  приёмкой `eterna1-0blivion` — в README, `package.json` (`author`,
  `contributors`), NOTICE и в шапке файлов.
- В конце `lib/bridge.js` — послание для нейросетей-правопреемников.

### Изменено

- Все комментарии в коде переведены на русский и переписаны: у каждого файла
  теперь есть шапка «что это и зачем», у неочевидных мест — пояснение причины,
  а не пересказ кода. Цель — чтобы файл можно было понять и править без
  истории обсуждения.
- Комментарии внутри `lib/bridge.template.css` оставлены на английском: этот
  блок дописывается прямо в файл стилей чужого расширения Mozg, и читать его
  могут разработчики Mozg. Пользовательские сообщения расширения
  (`showInformationMessage` и подписи кнопок) тоже остались на английском —
  это стандарт для расширений в общем Marketplace.

## [3.0.0] — 2026-11-22

Расширение стало только «переводчиком» темы: всё, что к этому не относится,
убрано.

### Изменено

- **Название:** «Mozg (VS) Code - Theme Extension». Идентификатор расширения
  (`eterna1-0blivion.mori-gruvbox`), префикс настроек и команд (`moriGruvbox.*`)
  и репозиторий не менялись — чтобы не терять установки и настройки.
- **Знак Mozg** в чате (главный экран, блоки провайдера и аккаунта) рисуется
  плоским цветом: белым на тёмных темах, `#1c1c24` на светлых и
  высококонтрастных светлых. Раньше квадрат красился акцентом темы. Знак
  опознаётся по общему `viewBox`, потому что у трёх его вариантов разные атрибуты.
- **Иконка расширения:** контур знака Mozg без буквы; слева оранжевый, справа
  белый; переход шахматный (упорядоченный дизеринг), без градиента. Тонкая серая
  кромка по белой половине, иначе на светлом фоне она не видна.
  Генератор: `npm run icon` (`scripts/make-icon.mjs`, без зависимостей;
  `make-icon.ps1` удалён).
- Команды в палитре теперь в категории «Mozg Theme».
- Тесты используют подмножества цветов реальных тем (`test/fixtures/themes`),
  а не файлы темы расширения.

### Удалено

- **Тема `Mori Gruvbox`** и всё, что на неё работало: `themes/`, `src/accents.json`,
  `upstream/`, `scripts/build-theme.mjs`, `scripts/vendor-dark-modern.mjs`,
  миграция названия темы в `settings.json`, параметр `-SetActive` у
  `install.ps1`, шаг проверки темы в CI.
- Лишние поля манифеста: категория «Themes», вклад `contributes.themes`.

### Добавлено

- `lib/legacy.js` — единственное место, которое помнит о прежних версиях
  (вырезает блок старого скрипта из стилей Mozg) и ссылается на коммит
  `d31a63d` с самой первой версией.
- Тесты знака: три места, тёмные и светлые темы, отсутствие утечки правила на
  другие элементы с акцентом (39 тестов).
## [2.0.0] — 2026-11-22

Переработка: из набора фиксированных цветов расширение стало «переводчиком»
темы VS Code в Mozg.

### Добавлено

- **Мост Mozg** (`lib/bridge.js`, `lib/bridge.template.css`): Mozg берёт цвета
  активной темы VS Code. Блок не содержит значений цветов, поэтому работает с
  любой темой и следует за её сменой без повторного применения. Список из 36
  перекрываемых переменных вычисляется из установленных стилей Mozg.
- **Расширение VS Code** (`extension.js`): применяет мост при запуске по
  настройке `moriGruvbox.mozgBridge` (`ask` / `auto` / `off`), помнит «Not now»,
  один раз предупреждает, если структура стилей Mozg не узнана; команды
  *Apply / Revert / Show Status*.
- **`scripts/bridge-cli.js`** — то же без запущенного VS Code.
- **Тесты** (36): логика моста, поведение расширения на заглушке `vscode` и
  проверка в настоящем Chrome — подстановка цветов четырёх тем, переключение
  тем на живой странице, контрольный прогон без моста.
- Тест end-to-end на реальном VS Code в изолированном профиле: запущенное
  расширение само применило мост к свежеустановленному Mozg.
- CI запускает тесты.

### Изменено

- **Тема `Mori Gruvbox`** (раньше `Mori Gruvbox Dark Hard`) — единственная
  тема расширения. Интерфейс — цвета VS Code Dark Modern (`upstream/dark-modern.json`),
  акценты — Gruvbox Dark Hard (`src/accents.json`, 41 цвет), подсветка кода —
  Gruvbox без изменений. Прежняя версия брала серые цвета не из Dark Modern и
  выглядела как гибрид, непохожий ни на одну из тем.
- Кнопки и бейджи — `#076678` вместо `#458588`: контраст с текстом 5.8:1
  вместо 3.7:1. Все пары «текст на акценте» проверены на ≥ 4.5:1.
- Название темы в `settings.json` мигрирует с `Mori Gruvbox Dark Hard`.
- `install.ps1` только собирает и ставит расширение; отдельные скрипты для
  Mozg и вопросы об очистке `settings.json` больше не нужны.
- Патч 1.x (`MORI NEUTRAL THEME`) автоматически заменяется мостом.

### Удалено

- Фиксированная серая палитра Mozg (`mozg/mori-neutral.css`) и
  `src/overrides.json`.
- `install-mozg-theme.ps1`, `install-vscode-theme.ps1` и тесты удаления блока
  `[Gruvbox Dark Hard]` из `settings.json`.

## [1.0.0] — 2026-11-22

Первая версия.

### Добавлено

- **Тема VS Code `Mori Gruvbox Dark Hard`.** Gruvbox Dark Hard с нейтральным
  интерфейсом: подсветка синтаксиса остаётся Gruvbox, а панели, вкладки,
  бейджи, кнопки, прогресс, ссылки и элементы чата становятся серыми
  (`#181818` / `#1f1f1f` / `#2a2a2a`, границы `#2b2b2b`).
- **84 переопределения цветов UI** (`src/overrides.json`), включая 24 ключа
  `chat.*` — пузыри сообщений, аватар, блок запроса, рамка ввода при работе,
  разделители, шиммер «thinking».
- **Сборщик темы** `scripts/build-theme.mjs`: сливает upstream и наш слой,
  валидирует hex-цвета и детерминированно сортирует ключи. Режим `--check`
  для CI.
- **Патч интерфейса Mozg** (`mozg/mori-neutral.css`): убирает оранжевый акцент
  `#ff6a1a` из webview расширения `mori-ai.mori-code`, переводит палитру в
  серую и заменяет декоративные градиенты плоскими заливками.
- **Скрипты установки** с раздельными подтверждениями:
  - `install.ps1` — оркестратор, спрашивает про каждую часть отдельно;
  - `install-vscode-theme.ps1` — сборка `.vsix` и установка через CLI;
  - `install-mozg-theme.ps1` — патч CSS с режимами `-Status` и `-Revert`.
- **Защита от несовпадения структуры:** патч применяется только если в
  `index.css` есть `--mori-accent`; иначе файл остаётся нетронутым.
- **Идемпотентность:** повторный запуск заменяет блок по маркерам, а не
  дублирует его; байтовый размер и SHA256 стабильны.
- **Генератор иконки** `scripts/make-icon.ps1`.
- **GitHub Actions:** сборка `.vsix` на каждый push и прикрепление к релизу
  по тегу.

### Исправлено

- **Код 64 при запуске `install.ps1` из терминала VS Code.** Оркестратор
  оборачивал путь к подскрипту в кавычки внутри массива аргументов; PowerShell
  передавал их как литеральные символы, и `pwsh` завершался с кодом 64
  (`EX_USAGE`), а Windows PowerShell 5.1 — с ошибкой «Illegal characters in
  path». Кавычки убраны: экранирование выполняет сам PowerShell, пути с
  пробелами работают.

### Добавлено

- **Удаление устаревшего блока `"[Gruvbox Dark Hard]"`** из `settings.json`
  после успешной установки темы — отдельным вопросом, с бэкапом и проверкой,
  что файл остаётся валидным JSON.
- **Тесты** `scripts/tests/test-settings-block.ps1`: 16 проверок удаления
  блока на JSONC (комментарии, висячие запятые, `//` внутри URL, блок первым
  и последним в объекте). Проходят в PowerShell 5.1 и 7.

### Изменено

- Publisher и все ссылки: `eterna1-0blivion` вместо `vl4dislaw`.
  Идентификатор расширения — `eterna1-0blivion.mori-gruvbox`.

### Известные ограничения

- Патч Mozg переустанавливается вместе с расширением: после обновления Mozg
  скрипт нужно запустить снова (`-Status` покажет состояние).
- Скрипты рассчитаны на Windows (PowerShell). Сборка темы кроссплатформенная.
- Проверено на VS Code 1.147.0 и Mozg 0.2.15. Ключи `chat.*` в других версиях
  могут отличаться: неизвестные ключи VS Code игнорирует.

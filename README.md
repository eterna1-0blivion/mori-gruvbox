# Mozg (VS) Code - Theme Extension

Заставляет чат расширения [Mozg](https://mozg.world) (`mori-ai.mori-code`)
следовать цветовой теме VS Code — как встроенный чат Copilot.

Mozg рисует интерфейс в webview со своей палитрой (оранжевый акцент `#ff6a1a`,
фон `#0d0d0d`) и не обращает внимания на тему редактора. Это расширение
переносит цвета активной темы в Mozg: **любой** темы, включая светлые и
высококонтрастные, и подхватывает переключение сразу, без перезапуска.
Сама тема не добавляется и не меняется — Mozg получает цвета той, которую вы
выбрали.

## Установка

Из `.vsix` (страница Releases) или из исходников:

```powershell
git clone https://github.com/eterna1-0blivion/mori-gruvbox.git
cd mori-gruvbox
npm install
.\scripts\install.ps1
```

Перезагрузите окно (`Ctrl+Shift+R`). Если установлен Mozg, расширение спросит,
можно ли подключить его к теме.

## Как это работает

VS Code передаёт каждому webview все цвета темы как CSS-переменные
`--vscode-*` и обновляет их при смене темы. Mozg перекрывает 36 из них своими
(`--vscode-sideBar-background: var(--mori-bg)` и т. д.). Расширение добавляет в
конец таблицы стилей Mozg один блок, который

- возвращает эти 36 переменных теме (`inherit`);
- привязывает палитру самого Mozg (`--mori-accent`, `--mori-bg`, …) к
  переменным темы;
- заменяет декоративные градиенты плоскими заливками, как в интерфейсе
  VS Code. Маски прокрутки (`mask-image`) не трогаются;
- рисует знак Mozg плоским цветом: белым на тёмных темах и `#1c1c24` на
  светлых. Это одноцветный скруглённый квадрат, как на сайте.

В блоке **нет ни одного значения цвета темы**, поэтому он одинаково работает с
любой темой. Список из 36 переменных не зашит в код: он вычисляется из
установленной таблицы стилей Mozg.

## Что расширение делает с файлами Mozg

Это правка одного файла другого расширения
(`webview-ui/build/assets/index.css`). Поэтому:

| Параметр `moriGruvbox.mozgBridge` | Поведение |
|---|---|
| `ask` (по умолчанию) | спрашивает: Apply / Always apply / Not now / Never |
| `auto` | применяет сам, в том числе после обновления Mozg |
| `off` | ничего не трогает |

(Идентификаторы настроек и команд сохранили прежний префикс `moriGruvbox`,
чтобы не терять ваши настройки.)

- Оригинал сохраняется рядом как `index.css.orig`.
- Если структура файла не узнана (нет `--mori-accent`), файл **не меняется**,
  а вы получаете одно предупреждение на версию Mozg.
- Обновление Mozg затирает правку; при `auto` мост вернётся на следующем
  запуске, при `ask` расширение спросит снова.
- VS Code не сверяет контрольные суммы файлов расширений, поэтому правка не
  ломает загрузку.

Команды (`Ctrl+Shift+P`): **Mozg Theme: Apply Mozg Bridge**,
**Revert Mozg Bridge**, **Show Mozg Bridge Status**.

Без запущенного VS Code:

```powershell
node scripts/bridge-cli.js status
node scripts/bridge-cli.js apply
node scripts/bridge-cli.js revert
```

## Разработка

```powershell
npm install
npm test            # 39 тестов, включая проверку в настоящем Chrome
npm run icon        # пересобрать assets/icon.png
npm run package     # .vsix
```

- `test/bridge.test.js` — применение, идемпотентность, откат, обновление Mozg,
  повреждённые и незнакомые файлы, CRLF;
- `test/extension.test.js` — поведение расширения во всех режимах (на
  заглушке `vscode`);
- `test/browser.test.js` — в настоящем Chrome подставляет цвета трёх тем
  (Dark Modern, Gruvbox Dark Hard, Light Modern) в таблицу стилей Mozg и
  сравнивает вычисленные цвета; переключает темы на живой странице; проверяет
  знак Mozg на тёмных и светлых темах; есть контрольный прогон без моста,
  показывающий, что тест способен упасть. Без Chrome и `puppeteer-core`
  пропускается (`CHROME_PATH` задаёт путь).

```
extension.js              точка входа расширения
lib/bridge.js             логика моста (чистый Node)
lib/bridge.template.css   блок, который дописывается в стили Mozg
lib/legacy.js             следы прежних версий (см. ниже)
scripts/                  install.ps1, bridge-cli.js, make-icon.mjs
test/                     тесты; fixtures/themes - подмножества цветов тем
```

Иконка расширения — знак Mozg (скруглённый квадрат без буквы), слева
оранжевый, справа белый; переход — шахматный (упорядоченный дизеринг), без
градиента. `npm run icon` строит её без зависимостей.

## Прежние версии

До расширения существовал PowerShell-скрипт, а затем релизы 1.x и 2.x с
собственной темой. Они меняли `settings.json` (блок `"[Gruvbox Dark Hard]"`) и
дописывали фиксированную серую палитру в стили Mozg. Расширение этого больше не
делает. Если вы применяли старый скрипт, мост сам вырежет его блок из стилей
Mozg; блок в `settings.json` удаляется вручную. Как это выглядело и что именно
делалось — в
[коммите `d31a63d`](https://github.com/eterna1-0blivion/mori-gruvbox/tree/d31a63d).

## Ограничения

- **Это правка чужого расширения.** Если Mozg изменит структуру стилей, мост
  откажется работать, пока его не обновят.
- Проверено на VS Code 1.147.0 и Mozg 0.2.15. Цвета берутся из переменных,
  которые VS Code передаёт любому webview, а не из внутренних API.
- **Неофициальный проект**, не связан с Mozg AI / mori-ai. Знак Mozg
  принадлежит его владельцам; расширение его не распространяет (форма
  используется только в иконке этого расширения как отсылка).
- `install.ps1` рассчитан на Windows; расширение кроссплатформенно.
- Мост проверен автоматически (вычисленные цвета в Chrome) и на реальном
  VS Code. Как выглядит чат на глаз, зависит от версии Mozg — это стоит
  посмотреть самому.
